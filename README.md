### Configurando o GIT e GITHUB

Conectar GIT ao GITHUB, digitar o seguinte comando no bash ou cmd:

`git config --global user.name "SeuUserName"`

`git config --global user.email "seu@email.com"`

confirmar com o comando:
`git config --list`
